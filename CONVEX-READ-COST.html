Unbounded index reads 16

An index chooses WHICH rows are read, never HOW MANY. A collect over an indexed range reads every row in it, and the range grows with the data.

Add .take(cap) at the read, or paginate. If the range is genuinely small, say so in a comment so the next reader does not have to guess.
